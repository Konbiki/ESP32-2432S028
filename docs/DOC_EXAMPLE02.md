# Example02_Text : 文字列描画サンプル

## サンプルについて

このサンプルは、Example01_LCDと同じLCD制御モジュールを用いて文字描画を行うサンプルです。  
枕草子を細切れに描画し、画面外になったらスクロールします。  
最後まで表示したら５秒待って、Example01_LCDと同様に90°回転させて同じ表示を行います。  
表示されるフォントには「東雲フォント 16px」を使用しています。  

基本的にはExample01_LCDのLCD制御モジュール(LCDManager)のDrawImageメソッドを用いて  
モノクロの文字データを描画しているに過ぎないのですが、  
文字描画モジュール/フォントデータはいくつかの形式に対応しており、  
単純なモノクロだけでなくグレイスケールやカラーパターンなんかも描画できたりします。  
あと単に文字を描画するだけでなく、コンソールの機能も実装しています。
(この辺はメインじゃないんで省略します)

構造は下記の様になっています。

```

アプリメイン(appmain)
　↓
ContoleManager(テキストコンソールモジュール)
　↓
TextWriter(文字描画モジュール)　   ←--  　フォントデータ
　↓ 描画指示
LCDManager(LCD制御モジュール:Examlpe01_LCD)

```


## TextWriter

TextWriterは初期化時に指定したフォントデータで  
任意の位置に任意の色の文字/文字列を描画します。

サンプルではモノクロの 8x16 または 16ｘ16 のフォントデータなので
0/1を点の色に変換し、一文字分の画素データを作ったら転送という感じです。


## ConsoleManager

ConsoleManagerは、テキストコンソール機能を提供します。  
文字単位の位置を指定して描画できますし、  
最後に描画した位置に続けて描画もされます。  
またエスケープシーケンスなんかにも対応してまして、  
位置を指定したり色を変更したりできます。  
描画位置が画面外になると自動的にスクロールします。

ただし、スクロールは全体的な描画しなおしになるので遅いです。。。
測定データなんかを表示する分には十分だと思いますが。
